Overdue work now has its own band at the top of Today and Upcoming, lists can be sorted, focus and filters and sort share one collapsible bar, and pinned projects live in your notes instead of in plugin settings.

**Overdue**
- A new **Overdue** band leads both **Today** and **Upcoming**, whatever sort or grouping you have set. It was previously a section you only saw when grouping by date.
- **Upcoming showed no overdue todos at all.** It looked forward only, so anything you had already missed was invisible on the one screen you plan the week from. It now runs from your oldest overdue todo through a week out, and its tab count matches.
- **Pull forward**, on the band, sets every overdue todo shown there to today. It only touches the rows on screen — whatever your filter and focus have narrowed to — never every overdue todo in the vault.

**Today**
- Today now **groups by status**, opening on **Doing** with the other sections folded. Overdue still leads, above all of them.
- Which sections are folded is remembered per segment, so Today, Upcoming, Reminders and Recent each keep their own, across restarts.
- Sort and group are now remembered **per segment** too. Setting Recent to sort by date no longer changes Today.

**Sorting**
- New **Sort** on List and project views: **Manual, Due, Priority, Title** and — where more than one project is on screen — **Project**. It orders todos inside each status section, never across them.
- **Manual** is the default and means file order, exactly as the note reads.
- Choosing any other sort turns off drag-to-reorder, since reordering a sorted list would write an order into your note that nothing on screen reflects.
- Remembered per view.

**One bar above every list**
- Focus, Filters and Sort are now a single section: the focus segments, then **Filters** on the left and **Sort** on the right. It replaces the standalone filter bar.
- The whole thing collapses to one line that still tells you where you are: **All | 0 filters | Manual**. It starts expanded, and remembers what you leave it as.

**Pinned projects**
- A pin is now a **`marktodo-pinned`** flag in the note's frontmatter rather than a setting, exactly like `marktodo-archived`.
- This means pins travel with your vault, survive renaming a project, and can be set from the MarkTodo Android app — which could not sync them before. Existing pins are converted automatically the first time you open Obsidian.

**Appearance**
- **New priority icons:** three ascending bars, filled to the level — replacing the flame for Urgent and the chevrons for High and Low.
- The focus row no longer takes an accent border when you narrow it. The summary line names the focus in words, which says it better.
- Selected items across MarkTodo are marked by a fill rather than an accent ring. A set filter now reads as a tinted field instead of one outlined like an error.

Note: if you had deliberately set Today to group by something, that choice is kept. Today only picks up the new status grouping if it was still on the old default of no grouping.
