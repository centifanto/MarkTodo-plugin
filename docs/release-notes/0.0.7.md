Statuses now run in phase order, any view can narrow to just what you are working on, and the todo dialogs have been rebuilt.

**Statuses**
- New order: **Backlog, Warming, Paused, Doing, Blocked, Done** — the three you plan with, then the three where work is live.
- Lists head each run with **Plan** or **Active**; boards rule a line between the two.
- A new focus row above every list and board — **All · Plan · Active · Doing**, with counts — narrows the view to one phase, or to Doing alone when all you want on screen is what you are actually working on.

**The todo dialogs**
- Rebuilt as a single label-and-control grid instead of stacked settings rows. The title and the note are click-to-edit.
- **Links work.** `[[a note]]`, `[label](https://…)` and bare URLs open from the editor; a note link opens the note, an external one goes to your browser.
- The project is now a dropdown in the editor, and "Move to project" in the todo menu opens a menu where you clicked instead of a full-screen picker.
- Adding a todo or a project opens the dialog over the `+` you pressed, not in the middle of the screen.

**Appearance**
- New **Settings → Appearance → Text size** (Smaller through Larger), scaling MarkTodo's own panes and dialogs. Everything else in Obsidian keeps the size your theme gives it.

**Fixes**
- The Convert button on an unmanaged Inbox todo now highlights on hover.

Note: existing project notes keep their current heading order. Only newly created `## Paused` headings are written in the new position.
