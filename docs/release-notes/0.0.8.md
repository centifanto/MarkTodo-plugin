Fixes the size of todo list text.

Todo rows were sized from Obsidian's **note** font size, while every other part of MarkTodo — including its own section headings and its board cards — used the interface sizes. In the dashboard column that left rows rendering larger than the headings above them, and **Settings → Appearance → Text size** scaled the two apart rather than together.

Rows now take the same base as the rest of MarkTodo, so a list, a board and the navigator are one size and Text size moves all of them at once.

If your lists now read smaller than you would like, **Text size → Large** is close to the old row size.
