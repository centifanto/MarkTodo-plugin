Todos now have **Steps**, and **New todo** includes a note field.

- Add, edit, check off, or remove steps inside a todo. Progress reads **2 of 4 steps done**.
- Indented Markdown checkboxes stay attached when their parent moves between status sections or projects. Completing the parent checks all its steps; deleting it removes them too.
- Search shows matching steps beneath their parent. Steps stay off boards and ordinary todo lists.
- Add a note while creating a todo; both save together.
